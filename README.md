# Magaalooyinka Soomaaliya

A guide to six Somali cities. Every city has its own page, and every famous place on that page has its own photograph.

## Cities

Muqdisho, Hargeysa, Garoowe, Berbera, Kismaayo, and Boosaaso.

## Run

Open `index.html` in a browser, then open a city page.

## Stack

HTML, CSS, and JavaScript. The words on the page are Somali.
